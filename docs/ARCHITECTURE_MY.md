# Yelinvoice Offline — နည်းပညာလမ်းညွှန်

ဤစာမျက်နှာတွင် Yelinvoice Android app ၏ အလုပ်လုပ်ပုံ၊ အဓိက source code ဖိုင်များနှင့် ပြင်ဆင်တည်ဆောက်ပုံကို မြန်မာဘာသာဖြင့် ရှင်းပြထားသည်။ အက်ပ်အကြောင်း မေးမြန်းသူများကို ဤလမ်းညွှန်နှင့် GitHub repository လင့်ခ်ကို မျှဝေနိုင်သည်။

**GitHub repository:** <https://github.com/yelin19/yelinvoice-apk>

## အက်ပ်၏ လုပ်ဆောင်ချက်များ

- မြန်မာနှင့် အင်္ဂလိပ်စာသားကို ဖုန်းပေါ်တွင်ပင် အသံဖိုင်အဖြစ် ဖန်တီးပေးသည် (TTS)။
- ပထမဆုံးအသုံးပြုချိန်တွင် ရွေးချယ်ထားသော အသံအမျိုးအစား (voice pack) ကို Hugging Face မှ ဒေါင်းလုဒ်လုပ်သည်။ ဒေါင်းလုဒ်ပြီးလျှင် အင်တာနက်မလိုဘဲ အသံဖန်တီးနိုင်သည်။
- `[00:00 - 00:03] စာသား` ကဲ့သို့ အချိန်မှတ်သားထားသော စာသားအလိုက် အသံကို သတ်မှတ်ချိန်တွင် ထည့်ပေးသည်။
- ဖန်တီးပြီးသော အသံများကို ဖုန်းထဲရှိ app သီးသန့်နေရာတွင် သိမ်းဆည်းကာ ပြန်ဖွင့်ခြင်း၊ အခြား app သို့မျှဝေခြင်း၊ ဖုန်းထဲသို့ သိမ်းခြင်းနှင့် တစ်ခုချင်းဖျက်ခြင်းတို့ လုပ်နိုင်သည်။
- တရုတ်စကားပြောကို စာသားအဖြစ်ပြောင်းပေးသည့် ရွေးချယ်နိုင်သော Whisper လုပ်ဆောင်ချက် ပါဝင်သည်။ Whisper မော်ဒယ်ကို APK ထဲတွင် မထည့်ထားပါ။ လိုအပ်မှသာ အက်ပ်အတွင်းမှ ခန့်မှန်းခြေ 547 MiB ရှိသော မော်ဒယ်ကို ဒေါင်းလုဒ်လုပ်နိုင်ပြီး၊ ဒေါင်းလုဒ်ပြီးနောက် အင်တာနက်မလိုဘဲ အသုံးပြုနိုင်သည်။

## အလုပ်လုပ်ပုံ အဆင့်ဆင့်

### ၁။ မျက်နှာပြင်နှင့် လုပ်ငန်းစဉ်စီမံခြင်း

`app/src/main/java/com/yelinvoice/offline/MainActivity.kt` သည် အက်ပ်မျက်နှာပြင်၊ အောက်ခြေတက်ဘ်များ၊ အသုံးပြုသူရွေးချယ်ချက်များ၊ လုပ်ငန်းစဉ်တိုးတက်မှုနှင့် အမှားအသိပေးချက်များကို စီမံသည်။ အသံဖန်တီးခြင်းနှင့် စာသားပြောင်းခြင်းကို အဓိကမျက်နှာပြင်ကို မရပ်တန့်စေရန် နောက်ခံလုပ်ငန်းစဉ်အဖြစ် လုပ်ဆောင်ပြီး၊ ရလဒ်နှင့် ရာခိုင်နှုန်းကို မျက်နှာပြင်သို့ ပြန်ပို့သည်။

### ၂။ စာသားမှ အသံဖန်တီးခြင်း (TTS)

1. `VoiceModelRepository.kt` သည် အသံအမျိုးအစားစာရင်း (catalog) မှ အသံအမည်၊ ဖိုင်လိပ်စာ၊ repository နှင့် revision အချက်အလက်များကို ဖတ်သည်။
2. လိုအပ်သော `encoder.onnx`, `decoder.onnx`, `voice.json` ဖိုင်များကို HTTPS မှတစ်ဆင့် ဒေါင်းလုဒ်လုပ်ပြီး SHA-256 ဖြင့် စစ်ဆေးသည်။ မှန်ကန်သော ဖိုင်များကို app သီးသန့်သိုလှောင်နေရာတွင် သိမ်းသည်။
3. `OfflineTtsEngine.kt` သည် Android အတွက် ONNX Runtime ဖြင့် encoder နှင့် decoder ကို ဖွင့်ပြီး အသံထုတ်သည်။
4. `app/src/main/python/nara_bridge.py` နှင့် `frontend/` အောက်ရှိ Python ဖိုင်များက မြန်မာဂဏန်းပြောင်းလဲခြင်း၊ မြန်မာစာအသံထွက်ပြင်ဆင်ခြင်းနှင့် အင်္ဂလိပ်စကားလုံးအသံထွက်ပြင်ဆင်ခြင်းတို့ကို လုပ်ပေးသည်။
5. ထွက်လာသောအသံကို 24 kHz၊ mono၊ PCM16 WAV ဖိုင်အဖြစ် ရေးသိမ်းသည်။ စာသားရှည်လျှင် အပိုင်းခွဲဖန်တီးပြီး တိုးတက်မှုကို ပြသသည်။

### ၃။ အချိန်မှတ်သားထားသော အသံဖန်တီးခြင်း

`TimestampDubbing.kt` တွင် စာသားခွဲခြမ်းဖတ်သည့် `TimestampTranscriptParser` နှင့် အသံဖိုင်တည်ဆောက်သည့် `TimestampDubRenderer` ပါဝင်သည်။ Parser သည် `[MM:SS - MM:SS]` သို့မဟုတ် `[HH:MM:SS - HH:MM:SS]` ပုံစံများကို ဖတ်ပြီး စတင်ချိန်၊ ပြီးဆုံးချိန်နှင့် စာသားကို ခွဲထုတ်သည်။ ပြီးဆုံးချိန်သည် စတင်ချိန်ထက် နောက်ကျရမည်။

Renderer သည် စုစုပေါင်းကြာချိန်အတွက် အသံတိတ် WAV လမ်းကြောင်းတစ်ခုကို အရင်တည်ဆောက်ပြီး စာကြောင်းတစ်ကြောင်းစီ၏ အသံကို သတ်မှတ်စတင်ချိန်တွင် ထည့်သည်။ စာကြောင်းမရှိသော ကွက်လပ်များကို အသံတိတ်ထားပြီး နောက်ဆုံးတွင် WAV ဖိုင်တစ်ဖိုင်တည်းအဖြစ် သိမ်းသည်။ အချိန်ကွက်ထက် အသံပိုရှည်သောအခါ WSOLA နည်းလမ်းဖြင့် အသံအမြင့် (pitch) ကို ထိန်းကာ အမြန်နှုန်းညှိနိုင်သည်။

### ၄။ အသံမှတ်တမ်းနှင့် ဖိုင်စီမံခြင်း

`AudioHistoryRepository.kt` သည် ဖန်တီးထားသော အသံဖိုင်များနှင့် မှတ်တမ်းများကို app သီးသန့်သိုလှောင်နေရာတွင် ထိန်းသိမ်းသည်။ ဖျက်ခြင်းလုပ်ဆောင်ချက်သည် ရွေးထားသော ဖိုင်တစ်ဖိုင်ကိုသာ ရည်ညွှန်းသည်။ အသုံးပြုသူသည် အသံဖွင့်နားထောင်ခြင်း၊ ဖုန်းထဲသို့ သိမ်းဆည်းခြင်းနှင့် အခြားသူထံ မျှဝေခြင်းတို့ ပြုလုပ်နိုင်သည်။

### ၅။ တရုတ်အသံမှ စာသားပြောင်းခြင်း (Whisper STT)

- `OfflineTranscriber.kt` သည် Android `MediaExtractor` နှင့် `MediaCodec` ကို အသုံးပြုပြီး ရွေးထားသော အသံဖိုင်ကို mono 16 kHz အသံဒေတာအဖြစ် ပြောင်းသည်။
- မော်ဒယ်ကို APK ထဲတွင် မပါဝင်စေဘဲ လိုအပ်သူကသာ အက်ပ်ထဲမှ သီးခြားဒေါင်းလုဒ်လုပ်နိုင်သည်။ ဒေါင်းလုဒ်ပြီးလျှင် SHA-1 တန်ဖိုးကို စစ်ဆေးပြီး app သီးသန့်သိုလှောင်နေရာတွင် သိမ်းသည်။
- `app/src/main/cpp/whisper-android/whisper_jni.cpp` သည် Kotlin/Java နှင့် whisper.cpp ကို JNI မှတစ်ဆင့် ချိတ်ဆက်သည်။ အသိအမှတ်ပြုမှု တိုးတက်မှုကို ပြန်ပို့ပြီး Whisper token အချိန်မှတ်တမ်းများကို အသုံးပြုကာ စာသားနှင့် timestamp များ ထုတ်ပေးသည်။
- တရုတ်ဘာသာကို ရွေးပြီး အသုံးပြုသည်။ မော်ဒယ်သည် 547 MiB ခန့်ရှိသောကြောင့် ဒေါင်းလုဒ်လုပ်ချိန်တွင် အင်တာနက်နှင့် ဖုန်းသိုလှောင်နေရာ လိုအပ်သည်။ RAM နည်းသောဖုန်းတွင် အချိန်ကြာနိုင်သည်။

## တည်ဆောက်ခြင်းနှင့် စမ်းသပ်ခြင်း

Android Studio ဖြင့် repository ကိုဖွင့်ပြီး Gradle Sync လုပ်ကာ `app` ကို build လုပ်နိုင်သည်။ Build ပတ်ဝန်းကျင်တွင် JDK 17၊ Android SDK 34၊ NDK 25.2.9519653၊ CMake 3.22.1၊ Python 3.10 နှင့် Gradle 8.2.1 လိုအပ်သည်။ GitHub Actions သည် `main` branch သို့ push လုပ်တိုင်း သို့မဟုတ် pull request တင်တိုင်း debug APK ကို တည်ဆောက်ပြီး `app-debug` ဟူသော artifact အဖြစ် သိမ်းသည်။

App ဗားရှင်းကို `app/build.gradle.kts` ရှိ `versionCode` နှင့် `versionName` တို့ဖြင့် သတ်မှတ်သည်။ ကြီးမားသော မော်ဒယ်ဖိုင်များကို source repository သို့မဟုတ် APK ထဲသို့ မထည့်ထားဘဲ၊ လိုအပ်သူက အက်ပ်ထဲမှ သီးခြားဒေါင်းလုဒ်လုပ်စေရန် စီစဉ်ထားသည်။

## အသံအမျိုးအစားအသစ် ထည့်ခြင်း

အသံစာရင်း၏ ပုံစံနမူနာကို `docs/voice_catalog.example.json` တွင် ကြည့်နိုင်သည်။ အသံအသစ်ထည့်ရာတွင် ကိုက်ညီသော `encoder.onnx`, `decoder.onnx`, `voice.json` ဖိုင်များ၊ HTTPS လိပ်စာ၊ ပြောင်းလဲမှုမရှိသော revision နှင့် SHA-256 တန်ဖိုးတို့ လိုအပ်သည်။ `model.safetensors` ဖိုင်တစ်ခုတည်းကို app က တိုက်ရိုက်သုံး၍ မရပါ—ဤ app နှင့် ကိုက်ညီသော ONNX ပုံစံသို့ ပြောင်းထားရမည်။

အခြားသူ၏အသံ၊ မော်ဒယ်နှင့် code ကို အသုံးပြုခြင်း သို့မဟုတ် ပြန်လည်ဖြန့်ဝေခြင်းမပြုမီ လိုင်စင်နှင့် ခွင့်ပြုချက်ကို စစ်ဆေးပါ။ အသေးစိတ်ကို `THIRD_PARTY_NOTICES.md` နှင့် `third_party/` ဖိုင်တွဲတွင် ကြည့်နိုင်သည်။

## ကန့်သတ်ချက်များ

- အသံအမျိုးအစားနှင့် Whisper မော်ဒယ်ကို ပထမဆုံးဒေါင်းလုဒ်လုပ်ရာတွင် အင်တာနက်လိုသည်။ အောင်မြင်စွာဒေါင်းလုဒ်လုပ်ပြီးလျှင် offline အသုံးပြုနိုင်သည်။
- ဤအက်ပ်သည် ကိုယ်ပိုင်အသံကို လေ့ကျင့်ပေးသော သို့မဟုတ် အသံတုပေးသော voice cloning စနစ် မဟုတ်ပါ။
- App ကို ဖျက်လိုက်ပါက app သီးသန့်နေရာထဲရှိ အသံမှတ်တမ်းများလည်း ဖျက်ပစ်နိုင်သည်။ လိုအပ်သောဖိုင်များကို ကြိုတင်ဖုန်းထဲသို့ သိမ်းပါ သို့မဟုတ် မျှဝေပါ။

## အခြားသူများထံ မျှဝေရန်

Source code နှင့် ဤလမ်းညွှန်ကို <https://github.com/yelin19/yelinvoice-apk> မှ ကြည့်ရှုနိုင်သည်။ APK ကို repository ၏ **Actions → Build Android APK** အပိုင်းရှိ အောင်မြင်ပြီးသော build artifact မှ ရယူနိုင်သည်။ Whisper နှင့် voice model ဖိုင်များကို APK ထဲတွင် မထည့်ထားပါ။
