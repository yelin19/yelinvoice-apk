# Yelinvoice Offline

ဒီ Android app သည် Hugging Face ပေါ်ရှိ Nara Mini နှင့် ကိုက်ညီသော ONNX အသံမော်ဒယ်ကို ဖုန်းထဲသို့ ဒေါင်းလုဒ်လုပ်ပြီး သိမ်းထားကာ မြန်မာနှင့် အင်္ဂလိပ်စာသားကို အင်တာနက်မလိုဘဲ အသံထုတ်ပေးရန် ရည်ရွယ်ထားပါသည်။ ၎င်းသည် စမ်းသပ်ဆဲ community project ဖြစ်ပြီး ကိုယ်ပိုင်အသံကို လေ့ကျင့်ပေးသော voice-cloning စနစ် မဟုတ်ပါ။

## App ထဲတွင် ပါဝင်သောအရာများ

- **ဖန်တီးမည်၊ အသံဖိုင်များ၊ Timestamp၊ စာသားထုတ်၊ ဆက်တင်များ** ဟူသော သီးခြားတက်ဘ်ငါးခုပါ Material Design 3 မျက်နှာပြင်။
- Nara Mini နှင့် ကိုက်ညီသော မြန်မာစာပြင်ဆင်မှု၊ မြန်မာဂဏန်းဖတ်နည်း၊ စက်ထဲတွင်ပဲ လုပ်ဆောင်သော အင်္ဂလိပ်အသံထွက်ပြောင်းလဲမှုနှင့် ONNX inference။ အင်္ဂလိပ်အသံထွက်အတွက် `g2p-en` ကိုသုံးပြီး လိုအပ်သော dictionary နှင့် tagger data များကို app ထဲတွင် ထည့်သွင်းထားသည်။
- အသံအမျိုးအစားလေးမျိုးကို ရွေးချယ်နိုင်ခြင်း။ ပထမဆုံးအသုံးပြုချိန်တွင် ရွေးထားသည့်အသံ၏ model ကို Hugging Face မှ HTTPS ဖြင့် ဒေါင်းလုဒ်လုပ်ပြီး SHA-256 ဖြင့် စစ်ဆေးသည်။ ဒေါင်းလုဒ်ပြီးသည့်နောက် အဲဒီအသံကို အင်တာနက်မရှိဘဲ အသုံးပြုနိုင်သည်။
- ဖန်တီးထားသော 24 kHz mono WAV ဖိုင်များကို app သီးသန့်သိုလှောင်ခန်းရှိ **အသံဖိုင်များ** စာရင်းထဲတွင် သိမ်းဆည်းခြင်း။ အဲဒီနေရာမှ ပြန်နားထောင်နိုင်၊ ဖုန်းထဲသို့ သိမ်းနိုင်၊ မျှဝေနိုင်၊ တစ်ခုချင်း ဖျက်နိုင်သည်။
- အသံဖွင့်နားထောင်ချိန်အတွက် 0.5× မှ 2.0× အထိ အမြန်နှုန်းပြောင်းနိုင်ခြင်း။ မူရင်း WAV ဖိုင်ကို မပြောင်းလဲပါ။
- Hugging Face repository မှ `voice_catalog.json` ကို ရယူခြင်း သို့မဟုတ် ဖုန်းထဲက JSON ဖိုင်ကို ထည့်သွင်းခြင်းဖြင့် voice pack အသစ်များ ထပ်ထည့်နိုင်ခြင်း။
- Timestamp dubbing တက်ဘ်တွင် `[00:00 - 00:03] စာသား` ပုံစံကို ဖတ်ပြီး interval အလိုက် မှန်ကန်သောအချိန်နေရာတွင် အသံချထားသည်။ အချိန်ကွက်လပ်များကို တိတ်ဆိတ်ထားပြီး၊ ရလဒ်ကို **WAV ဖိုင်တစ်ဖိုင်တည်း** အဖြစ် History ထဲသိမ်းသည်။ Slot အရှည်အတွင်း အသံမဝင်လျှင် စကားမဖြတ်ဘဲ pitch မပြောင်းစေသော အမြန်နှုန်းညှိခြင်းကို လုပ်သည်။
- **စာသားထုတ်** တက်ဘ်တွင် whisper.cpp ကို အသုံးပြုပြီး ဖုန်းထဲမှ အသံဖိုင်ကို offline ဖြင့် မြန်မာ သို့မဟုတ် တရုတ် (简体/繁體) timestamp ပါသောစာသားအဖြစ် ပြောင်းခြင်း။

## အသုံးပြုပုံနှင့် အင်တာနက်လိုအပ်ချက်

**ဖန်တီးမည်** တက်ဘ်တွင် အသံတစ်မျိုးရွေးပြီး စာသားထည့်ပါ။ ပထမဆုံးထုတ်လုပ်ချိန်တွင် အဲဒီအသံ၏ model ဖိုင်များကို ဒေါင်းလုဒ်လုပ်ပါမည်။ အသံဖိုင်ဖန်တီးပြီးလျှင် **အသံဖိုင်များ** တက်ဘ်တွင် ပြန်ဖွင့်ခြင်း၊ အမြန်နှုန်းညှိခြင်း၊ ဖုန်းထဲသို့ သိမ်းခြင်း၊ မျှဝေခြင်း သို့မဟုတ် ဖျက်ခြင်းတို့ လုပ်နိုင်ပါသည်။

အသံ pack တစ်ခုလျှင် ခန့်မှန်းခြေ 173–190 MB ရှိနိုင်ပါသည်။ ပထမအကြိမ်ဒေါင်းလုဒ်လုပ်ချိန်တွင် Wi-Fi နှင့် လုံလောက်သော သိုလှောင်နေရာကို အသုံးပြုပါ။ ရွေးထားသော pack ကို ဒေါင်းလုဒ်ပြီးသည်နှင့် အသံဖန်တီးခြင်း၊ အသံဖွင့်ခြင်း၊ history၊ သိမ်းခြင်းနှင့် မျှဝေခြင်းတို့ကို အင်တာနက်မရှိဘဲ လုပ်ဆောင်နိုင်သည်။ Hugging Face မှ catalog သို့မဟုတ် model အသစ်ဒေါင်းလုဒ်လုပ်ရန်သာ အင်တာနက်လိုသည်။

Whisper tiny multilingual model သည် ပထမဆုံး **စာသားထုတ်** လုပ်သည့်အခါ Hugging Face မှ ခန့်မှန်းခြေ 74 MiB ဒေါင်းလုဒ်လုပ်သည်။ ဒေါင်းလုဒ်နှင့် checksum စစ်ဆေးပြီးနောက် model ကို app-private storage ထဲတွင်ထားကာ နောက်တစ်ကြိမ်မှစ၍ offline အသုံးပြုသည်။ Audio ကို Android MediaCodec ဖြင့် mono 16 kHz ပြောင်းပြီး Whisper ကို မြန်မာ (`my`) သို့မဟုတ် တရုတ် (`zh`) language code ဖြင့် အသုံးပြုသည်။ Tiny model သည် Burmese အတွက် အကြီးစား model များထက် မှားယွင်းမှုများနိုင်ပြီး လက်တွေ့အသံများဖြင့် ထပ်မံစမ်းသပ်ရန် လိုအပ်သည်။

## Voice pack အသစ်ထည့်နည်း

လက်ရှိ app ထဲတွင် `yelin201875/Yelinvoice` repository မှ Shoon, Thazin, Ko Banyar နှင့် Htet Myat ဟူသော pack လေးမျိုးကို ထည့်ပေးထားသည်။ ဒီ repository snapshot ထဲက အသံများသည် Nara Mini v1 ၏ ရှိပြီးသား voice များဖြစ်ပြီး အသစ်လေ့ကျင့်ထားသော ကိုယ်ပိုင်အသံများ မဟုတ်ပါ။

Hugging Face မှ catalog ရယူလိုပါက **ဆက်တင်များ** တက်ဘ်ထဲရှိ repository URL နေရာတွင် `https://huggingface.co/owner/repo` ကို ထည့်ပါ။ Repository တွင် `voice_catalog.json` ဖိုင်ကို root မှာ တင်ထားရပါမည်။ သတ်မှတ်ထားသော commit ကို အသုံးပြုလိုပါက `https://huggingface.co/owner/repo/tree/COMMIT_SHA` ပုံစံဖြင့် ထည့်နိုင်သည်။ JSON ကို ဖုန်းထဲကနေ တိုက်ရိုက်ရွေးထည့်ရန်လည်း ရပါသည်။

ပုံစံနမူနာကို [`docs/voice_catalog.example.json`](docs/voice_catalog.example.json) တွင် ကြည့်နိုင်ပါသည်။ JSON တွင် `schemaVersion` သည် `1` ဖြစ်ရမည်။ `repository` နှင့် မပြောင်းလဲသော commit `revision` ကို ဖော်ပြပါ။ Voice တစ်ခုချင်းစီအတွက် သီးခြား `id`, `label` နှင့် `encoder.onnx`, `decoder.onnx`, `voice.json` ဖိုင်သုံးခု၏ path၊ SHA-256 တန်ဖိုးများကို ထည့်ပါ။ SHA-256 တန်ဖိုးသည် အမှန်တကယ် file တန်ဖိုးနှင့် ကိုက်ညီရမည်။ App သည် HTTPS Hugging Face လိပ်စာမှပဲ ရယူပြီး checksum မကိုက်သည့် pack ကို လက်မခံပါ။

Voice အသစ်၏ဖိုင်များသည် Nara Mini-compatible ONNX encoder/decoder နှင့် ကိုက်ညီသော `voice.json` vocabulary/style metadata ဖြစ်ရပါမည်။ `model.safetensors` checkpoint တစ်ခုတည်းကို ထည့်ရုံဖြင့် ဒီ app တွင် အသုံးမပြုနိုင်ပါ။ မတူညီသော model architecture ဆိုလျှင် ဒီ app နှင့် ကိုက်ညီသည့် ONNX ဖိုင်များအဖြစ် export လုပ်ရန် လိုအပ်သည်။ အခြားသူ၏အသံကို ထည့်မည်ဆိုလျှင် အသုံးပြုခွင့်နှင့် ဖြန့်ဝေခွင့် ရှိကြောင်း အရင်စစ်ဆေးပါ။

## Build လုပ်ရန်

Android Studio တွင် project ကိုဖွင့်ပြီး Gradle sync လုပ်ကာ `app` module ကို build လုပ်ပါ။ Build ပတ်ဝန်းကျင်တွင် JDK 17၊ Android SDK 34၊ NDK 25.2၊ CMake 3.22.1၊ Python 3.10 နှင့် Gradle 8.2.1 လိုအပ်သည်။ GitHub Actions က `main` branch push နှင့် pull request များတွင် Kotlin, Chaquopy Python နှင့် whisper.cpp JNI native library ပါသော debug APK build ကို စမ်းသပ်သည်။

## ကန့်သတ်ချက်များ

လုပ်ဆောင်နှုန်းသည် ဖုန်း၏ CPU၊ memory နှင့် သိုလှောင်နေရာပေါ် မူတည်သည်။ စာသားရှည်များကို အပိုင်းခွဲဖတ်သော်လည်း ဖုန်းအမျိုးမျိုးတွင် ထပ်မံစမ်းသပ်ရန် လိုအပ်သေးသည်။ အမြန်နှုန်းထိန်းချုပ်မှုသည် playback ပေါ်သာ သက်ရောက်ပြီး အမြန်နှုန်းပြောင်းထားသော WAV ဖိုင်အသစ် ဖန်တီးခြင်း မဟုတ်ပါ။ App တွင် voice training သို့မဟုတ် user အသံဖိုင်ဖြင့် voice clone လုပ်ခြင်း မပါဝင်ပါ။

ပြင်ပ code၊ data နှင့် model များ၏ လိုင်စင်အသိပေးချက်ကို [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) နှင့် `third_party/` ဖိုင်တွဲတွင် ကြည့်နိုင်သည်။
