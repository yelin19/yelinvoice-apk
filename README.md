# Yelinvoice Offline

ဒီ Android app က Nara Mini v1 ရဲ့ ONNX အသံမော်ဒယ်တွေကို ဖုန်းထဲ ဒေါင်းလုဒ်လုပ်ပြီး သိမ်းထားကာ၊ နောက်ပိုင်း အင်တာနက်မလိုဘဲ မြန်မာစာကို အသံထုတ်ပေးနိုင်ဖို့ ရည်ရွယ်ထားတဲ့ စမ်းသပ်ဆဲ project ဖြစ်ပါတယ်။

## လက်ရှိပါဝင်တဲ့အရာများ

- Kotlin နဲ့ရေးထားတဲ့ Android app မျက်နှာပြင်နဲ့ အသံရွေးချယ်စရာ။
- App ကို ပထမဆုံးဖွင့်တဲ့အခါ Shoon အသံမော်ဒယ်ကို ဒေါင်းလုဒ်လုပ်ပါတယ်။ အခြားအသံကို ရွေးပြီး အသုံးပြုတဲ့အခါ အဲဒီအသံရဲ့ model ကို ဒေါင်းလုဒ်လုပ်ပါတယ်။
- `encoder.onnx`, `decoder.onnx`, `voice.json` ဖိုင်တွေကို ဖုန်းရဲ့ app သီးသန့်သိုလှောင်ခန်းမှာ သိမ်းပါတယ်။
- ဒေါင်းလုဒ်ထားတဲ့ model ဖိုင်တွေကို SHA-256 နဲ့ စစ်ဆေးပါတယ်။
- မြန်မာစာပြင်ဆင်ခြင်းနဲ့ ONNX inference ကို ဖုန်းပေါ်မှာ လုပ်ဆောင်ပါတယ်။
- အသံကို 24 kHz, mono WAV ဖိုင်အဖြစ် သိမ်းပြီး app ထဲမှာ ပြန်ဖွင့်နိုင်ပါတယ်။

အသံတစ်ခုရဲ့ model ဖိုင်တွေ စုစုပေါင်း 190 MB ဝန်းကျင်ရှိနိုင်ပါတယ်။ ပထမဆုံးဒေါင်းလုဒ်လုပ်ချိန်မှာ Wi-Fi သုံးပါ၊ ဖုန်းထဲမှာ လုံလောက်တဲ့ သိုလှောင်နေရာရှိကြောင်း စစ်ဆေးပါ။ Model ဒေါင်းလုဒ်လုပ်ပြီးနောက် အဲဒီအသံကို အင်တာနက်မလိုဘဲ အသုံးပြုနိုင်ပါတယ်။

## Build လုပ်ရန်

Android Studio မှာ project ကိုဖွင့်ပြီး Gradle sync လုပ်ကာ `app` module ကို build လုပ်ပါ။ Build ပတ်ဝန်းကျင်မှာ JDK 17၊ Android SDK 34၊ Python 3.10 နဲ့ Gradle 8.2.1 လိုအပ်ပါတယ်။

GitHub Actions က `main` branch ကို push လုပ်တိုင်းနဲ့ pull request တင်တိုင်း debug APK တည်ဆောက်နိုင်မနိုင် စစ်ဆေးပါတယ်။ Build အောင်မြင်ရင် APK ကို workflow run ရဲ့ artifact အဖြစ် ဒေါင်းလုဒ်လုပ်နိုင်ပါတယ်။

## Model ရယူရာနေရာ

App က Nara Mini v1 ရဲ့ Hugging Face repository မှာ သတ်မှတ်ထားတဲ့ version ကို အသုံးပြုပြီး model ဖိုင်တွေကို ဒေါင်းလုဒ်လုပ်ပါတယ်။ အရွယ်အစားကြီးတဲ့ ONNX model ဖိုင်တွေကို ဒီ GitHub project ထဲ မထည့်ထားပါ။ ဒေါင်းလုဒ်လုပ်ထားတဲ့ ဖိုင်တွေရဲ့ SHA-256 ကို စစ်ဆေးပါတယ်။

## လက်ရှိကန့်သတ်ချက်များ

ဒီဟာက စမ်းသပ်ဆဲ ပထမဗားရှင်းဖြစ်ပြီး Nara Mini ရဲ့ လုပ်ဆောင်ချက်အားလုံး မပါသေးပါ။ လက်ရှိမှာ မြန်မာစာနဲ့ Nara Mini မှာ ကြိုတင်ပါဝင်တဲ့ အသံလေးမျိုးကိုသာ အသုံးပြုနိုင်ပါတယ်။ အင်္ဂလိပ်စာအသံထွက်ပြောင်းလဲခြင်းကို မပံ့ပိုးသေးပါ။ Android ဖုန်းအမျိုးမျိုးမှာ လုပ်ဆောင်နှုန်းကို အပြည့်အဝ မစမ်းသပ်ရသေးပါ။ **ကိုယ်ပိုင်အသံကို ပုံတူကူးပြီး လေ့ကျင့်ပေးတဲ့ voice cloning လုပ်ဆောင်ချက် မပါသေးပါ။**

စာသားပြင်ဆင်တဲ့အပိုင်းကို Nara Mini v1 ရဲ့ Apache-2.0 လိုင်စင်ပါ Burmese frontend မှ ယူထားပါတယ်။ အသေးစိတ်ကို `THIRD_PARTY_NOTICES.md` နဲ့ `third_party/nara-mini/` ဖိုင်တွဲမှာ ကြည့်နိုင်ပါတယ်။
